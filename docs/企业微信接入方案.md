# 企业微信接入方案（2026-08-09：V2 受阻，降级只做 V1 出向通知）

> ⛔ **2026-08-09 部署实测裁定：V2 入向发单放弃**。企微「接收消息」回调要求 URL 域名**在大陆 ICP 备案且备案主体与企微注册公司主体一致**（报错「Domain entity verification failed」）；致同老挝无大陆备案主体，腾讯云默认 `tencentscf.com` 域名过不了核验。故 V2 无法落地，为 V2 建的腾讯云函数 `wecom` 可删除。
> **最终形态：企业微信只做 V1 出向通知**（群机器人 webhook，无回调、无备案、无云函数）。**发单入口仍是 Telegram + claude.ai App MP Project** 两条（均已通）。
> 代码归属 ztl-symphony（本仓库只放方案与决策）。

## 与 Telegram 网关的关键差异

Telegram 是**长轮询**——本地进程主动拉消息，不需要公网地址。企业微信入向是**回调制**——企微服务器把消息 POST 到你配置的公网 HTTPS URL（需 URL 验签 + AES 解密）。所以企微入向**必须有一个公网可达的端点**，本地长轮询模式套不上。这决定了架构：入向走 serverless 云函数，不上常驻服务器。

## 架构（两期走）

### V1 出向通知（先做，半天量级）

```
执行侧（orchestrator / 云端会话）任务完成或【待决策】
   → POST 企微群机器人 webhook（一个 URL，无需公网端点、无需回调配置）
   → 企微群里收到摘要/待决策清单
```

- 用企微「群机器人」：企微群 → 添加机器人 → 得到 webhook URL，配进 symphony 环境变量（如 `MP_WECOM_WEBHOOK`）。
- 推送时机与 Telegram 通知并行：完成、卡住、待决策三个时点，内容遵守汇报纪律（三段 ≤8 行）。
- 局限：群机器人只能发不能收，所以 V1 里在企微回 `symphony: 1A 2B` 没用，决策仍回 Telegram 或 App。

### ⛔ V2 入向发单（回调网关，serverless）—— 2026-08-09 放弃，存档备查

**放弃原因**：企微接收消息回调强制「大陆 ICP 备案 + 备案主体匹配公司主体」域名核验，致同老挝无法满足。以下架构存档，若日后有大陆关联主体+备案域名可绑为函数自定义域名后重启。代码已在 ztl-symphony `feat/wecom-gateway` 分支（含云函数、部署文档），保留不删，作 V1 群机器人推送封装的来源。

```
企微 App 发消息（自建应用「MP」）
   → 企微服务器回调 POST → 云函数（腾讯云 SCF，与企微同生态，免运维）
      ①验签（token）+ AES 解密（EncodingAESKey）
      ②白名单校验（仅你的企微 userid，其余静默丢弃）
      ③调 Anthropic API 跑一轮 headless MP 定域（复用 symphony gateway/mp-dispatch.js 的 prompt 逻辑）
      ④按 dida-board-contract.md 建卡（Todo 列 + agent-ready + ws-<代号>）
      ⑤企微被动回复「已定域到 X，已入队」
   → 本地 orchestrator（或未来云端会话）认领执行
   → 回报经 V1 的群机器人 webhook 推回企微
   → 你在企微回 `symphony: 1A 2B` → 回调再走一遍 ③④ 的续跑分支
```

- 云函数无状态、按调用计费（个人用量≈0 成本），不引入常驻组件，符合去单机化方向。
- 凭据全走云函数环境变量：`corpid`、`corpsecret`、回调 `token`/`EncodingAESKey`、`ANTHROPIC_API_KEY`、滴答凭据。凭据放置由用户人工操作，agent 不代劳。

## 你的前置准备（V2 动工前人工完成）

1. 企微管理后台 → 应用管理 → **创建自建应用**（名字建议「MP」），记下 `AgentId`、`Secret`、企业 `CorpId`。
2. 应用「接收消息」处生成 `Token` 与 `EncodingAESKey`（先留着，云函数部署好拿到 URL 后回来填）。
3. 开通一个腾讯云账号（云函数 SCF 免费额度即够）。
4. V1 只需：建一个企微群（哪怕只有你一人）→ 添加群机器人 → 把 webhook URL 交给 symphony 会话配置。

## 风险与边界

- **安全**：回调必须验签+解密+userid 白名单三关全过；云函数 URL 不出现在任何公开文档。
- **企微消息 5 秒回包限制**：MP 定域可能超 5 秒，回调先回「收到，处理中」，定域结果经应用消息/群机器人异步推送。
- 红线不变：对外提交类动作在企微里也一律 GATE_CONFIRM，等你明确回复才继续。
